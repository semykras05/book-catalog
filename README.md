# Лабораторна робота №4

## Тема, мета та опис проєкту

**Тема:** Препроцесор SCSS та адаптивний дизайн веб-сторінки.

**Мета:** Навчитися організовувати стилі за допомогою SCSS, використовувати змінні, вкладені правила, міксіни та модулі, компілювати SCSS у CSS і адаптувати макет наскрізного сайту для мобільних, планшетних і настільних екранів.

**Опис проєкту:** Продовження наскрізного вебзастосунку **BookShelf — «Каталог книг»** після лабораторної роботи №3. HTML-розмітку, картки книг та форму рекомендації збережено; усі стилі перенесено на препроцесор SCSS і адаптовано під різні ширини екрана без використання JavaScript.

## Структура SCSS та використані можливості

Стилі поділено на модулі в папці `scss/` і підключено до `scss/main.scss` через сучасне правило `@use` (без застарілого `@import`):

- `scss/_variables.scss` — повторювані змінні кольорів (`$color-primary`, `$color-surface`, `$color-text`, `$color-border`, `$color-focus`, `$color-error`), шрифту (`$font-main`), шкали відступів (`$space-xs`–`$space-xl`), радіусів (`$radius-sm`, `$radius-md`), ширини контейнера (`$container-max`) і точок переходу (`$bp-tablet`, `$bp-desktop`).
- `scss/_mixins.scss` — параметризований міксін `respond-from($breakpoint)` для медіазапитів `min-width` та міксін `focus-ring($color, $offset)` для єдиного оформлення клавіатурного фокусу.
- `scss/main.scss` — основні стилі компонентів із доречною вкладеністю (`.main-nav`, `.card`, `.button`, `.request-form`, `.site-footer`) та використанням селектора `&` для станів `:hover`, `:focus-visible`, `:focus:invalid` і модифікатора `&.button-secondary`.
- `css/styles.css` — результат компіляції Dart Sass (вручну не редагується).

## Команди встановлення та компіляції

```bash
# Встановлення залежностей
npm install

# Одноразова компіляція SCSS у CSS
npx sass scss/main.scss:css/styles.css

# Режим відстеження змін під час розробки
npx sass --watch scss/main.scss:css/styles.css
