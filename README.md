# Лабораторна робота №3

## Тема, мета та опис проєкту

**Тема:** Компонування вебсторінки та створення форм. Побудова макета вебсторінки засобами CSS Flexbox і Grid. Створення, оформлення та базова перевірка HTML-форми.

**Мета:** Навчитися свідомо обирати Flexbox або Grid для компонування елементів, керувати напрямком, вирівнюванням і проміжками, а також створювати семантичну й доступну форму з підписами, різними типами полів і вбудованою HTML-перевіркою.

**Опис проєкту:** Продовження наскрізного вебзастосунку **BookShelf — «Каталог книг»**. У межах лабораторної роботи №3 вдосконалено макет сторінки за допомогою Flexbox і Grid без використання медіазапитів, SCSS і JavaScript, а також додано інтерактивну HTML-форму запиту на підбір книги.

## Компонування сторінки

- **Flexbox (одновимірне компонування):**
  - `.nav-list` — горизонтальний рядок навігації з перенесенням елементів (`flex-wrap: wrap`), вирівнюванням (`align-items: center`) і проміжками (`gap`).
  - `.card` — вертикальна колонка (`flex-direction: column`), що дозволяє вирівняти кнопки дій у нижній частині карток через `margin-top: auto`.
  - `.format-options` та `.form-actions` — гнучкі ряди радіокнопок і кнопок форми з рівними проміжками `gap`.
- **Grid (двовимірне компонування):**
  - `.cards-list` — двовимірна сітка для трьох однотипних карток книг (`grid-template-columns: repeat(auto-fit, minmax(240px, 1fr))` та `gap: var(--space)` без зовнішніх `margin`).
  - `.request-form` та `.form-field` — сітка вертикального розташування полів форми та їхніх підписів із повторним використанням CSS-змінних із лабораторної роботи №2.

## Форма та перевірка даних

Додано секцію «Запит на рекомендацію книги» (`<form class="request-form">`), де кожне поле має унікальний `id`, атрибут `name` та видимий зв'язаний `<label for="...">`:

- `book-query` (`type="text"`) — запит або тема книги (`required`, `minlength="2"`, `maxlength="80"`).
- `reader-email` (`type="email"`) — електронна пошта для відповіді (`required`, перевірка формату email).
- `book-genre` (`<select>`) — вибір жанру зі списку (`required`).
- `book-format` (`<fieldset>` + `<legend>` + 3 радіокнопки `type="radio"`) — вибір формату видання (паперова, електронна, аудіокнига).
- `max-pages` (`type="number"`) — бажаний максимальний обсяг сторінок (`min="50"`, `max="1500"`).
- `book-notes` (`<textarea>`) — додаткові побажання (`required`, `minlength="10"`).
- Кнопки `submit` («Отримати рекомендацію») та `reset` («Очистити форму») зі станами `:hover`, а також стани `:focus-visible` та `:focus:invalid` для всіх елементів керування.
