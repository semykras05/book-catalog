# Лабораторна робота №10

## Тема, мета та команди запуску

**Тема:** Маршрутизація та спільний стан у Vue 3 із Vue Router і Pinia. Створення багатосторінкового сценарію в односторінковому Vue-застосунку та організація спільного стану.

**Мета:** Навчитися встановлювати й налаштовувати Vue Router і Pinia, створювати маршрути списку та детальної сторінки, передавати параметр `id`, знаходити об’єкт у сховищі та змінювати спільний стан без зовнішнього API.

**Команди встановлення, запуску та збірки:**
```bash
cd books-vue
npm install
npm install vue-router pinia
npm run dev
npm run build
