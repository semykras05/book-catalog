# Лабораторна робота №6

## Тема, мета та опис проєкту

**Тема:** Дані та динамічне формування DOM засобами JavaScript. Масиви та об’єкти JavaScript. Динамічне формування контенту, пошук і фільтрація даних.

**Мета:** Навчитися описувати предметні дані масивом об’єктів, перетворювати дані на HTML-картки, оновлювати DOM і реалізовувати пошук та фільтрацію без перезавантаження сторінки.

**Локальний запуск:** відкрити папку проєкту у VS Code та запустити `index.html` через розширення **Live Server** (`http://127.0.0.1:5500/`). За потреби перекомпілювати стилі командою `npx sass scss/main.scss:css/styles.css`.

## Структура даних та категорії

Статичні картки книг видалено з `index.html`, а дані винесено в масив `books` із **8 об’єктів** у файлі `js/scripts.js` (підключеному через `<script src="js/scripts.js" defer></script>`).

Кожний об’єкт описує книгу такими властивостями:
- `id` — унікальний числовий ідентифікатор;
- `title` — назва книги;
- `author` — автор видання;
- `category` — код категорії, що відповідає `value` у `<select>`;
- `description` — короткий опис книги;
- `image` — відносний шлях до зображення обкладинки.

**Перелік категорій (`#category-filter`):**
- `all` — Усі;
- `fiction` — Художня література;
- `scifi` — Фантастика та фентезі;
- `it` — Програмування та ІТ;
- `nonfiction` — Саморозвиток та історія.

## Пояснення основних функцій

- `createBookCard(book)` — приймає один об’єкт книги та за допомогою шаблонного рядка формує HTML-розмітку картки `<article class="card" data-id="...">` з обкладинкою, категорією, назвою, автором та описом.
- `renderBooks(booksToRender)` — перетворює переданий масив об’єктів на HTML-рядки методом `map(createBookCard)`, об’єднує їх через `join("")`, оновлює `#book-grid`, виводить кількість у `#results-count` та керує видимістю `#empty-message` через властивість `hidden`.
- `applyFilters()` — зчитує рядок пошуку (`trim().toLowerCase()`) та обрану категорію, фільтрує вихідний масив `books` методом `filter()` без його зміни (одночасно перевіряючи входження тексту в назву, автора або опис і збіг категорії) та передає результат у `renderBooks()`.

## Перевірені сценарії та обмеження

**Перевірені сценарії:**
- після завантаження сторінки відображаються всі 8 карток і лічильник `Знайдено: 8`;
- пошук працює в реальному часі (подія `input`) без урахування регістру за назвою, автором та описом;
- вибір категорії (подія `change`) залишає лише відповідні книги;
- пошук і категорія працюють одночасно, звужуючи спільну вибірку;
- очищення пошуку й вибір «Усі» відновлюють повний каталог;
- за відсутності збігів контейнер порожній, лічильник показує `Знайдено: 0`, відображається повідомлення «Нічого не знайдено.»;
- у Console DevTools немає помилок.

**Відомі обмеження:** дані зберігаються статично в масиві `js/scripts.js` без підключення зовнішнього API, сервера або `localStorage`; використання `innerHTML` застосовується лише для контрольованого статичного масиву розробника.
