# Лабораторна робота №5

## Тема, мета та опис проєкту

**Тема:** Основи JavaScript. Взаємодія з DOM та подіями. Підключення JavaScript до вебсторінки, пошук елементів у DOM, обробка подій та зміна стану інтерфейсу.

**Мета:** Навчитися підключати зовнішній JavaScript-файл, знаходити наявні HTML-елементи, реагувати на дії користувача та змінювати класи й текстовий вміст елементів, додавши до наскрізного сайту 2–3 прості інтерактивні можливості.

**Опис проєкту:** Продовження адаптивного вебзастосунку **BookShelf — «Каталог книг»** після лабораторної роботи №4. HTML-структуру та дизайн збережено; сторінка отримала базову клієнтську інтерактивність через зовнішній скрипт `js/main.js`, підключений із атрибутом `defer`, без використання масивів даних, циклів, `localStorage` або API.

## Реалізовані інтерактивні можливості

1. **Показ і приховування додаткового опису («Показати більше» / «Приховати»):** у секції «Про сервіс» кнопка `.details-toggle` перемикає видимість блока `#extra-details` за допомогою класу `.is-hidden`, змінює власний текст і оновлює атрибут `aria-expanded`.
2. **Додавання книги в обране («Додати в обране» / «В обраному»):** на картці книги «1984» (`#featured-book-card`) кнопка `.favorite-button` перемикає клас `.is-active` для кнопки та картки, змінює текст кнопки і синхронізує атрибут `aria-pressed`.
3. **Лічильник місячної цілі читання (`−` / `+`):** у секції «Персональний список читання» кнопки `#counter-decrement` та `#counter-increment` змінюють числове значення цілі у межах від `1` до `12`, оновлюють текстовий статус і застосовують клас `.is-disabled` на межах діапазону.

## Використані DOM-методи, події та CSS-стани

- **Підключення скрипта:** `<script src="js/main.js" defer></script>` у `<head>`.
- **Пошук елементів:** `document.querySelector()` для отримання кнопок і цільових блоків DOM.
- **Події:** `addEventListener("click", ...)` для обробки натискань мишею та з клавіатури (`Enter` / `Space`).
- **Оновлення інтерфейсу:** `classList.toggle()` (класи станів `.is-hidden`, `.is-active`, `.is-disabled` без inline-стилів), `textContent` для безпечного оновлення тексту та `setAttribute()` для синхронізації `aria-expanded` і `aria-pressed`.
