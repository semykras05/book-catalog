# Лабораторна робота №7

## Тема, мета та спосіб запуску

**Тема:** Модульний каталог та асинхронне завантаження даних. ES Modules, `async/await`, замикання та чисті функції у JavaScript.

**Мета:** Розвинути каталог книг **BookShelf** із лабораторної роботи №6: винести предметні дані в `data/items.json`, розділити JavaScript на модулі, реалізувати асинхронне завантаження через `fetch()` з обробкою станів і помилок, а також застосувати замикання для відкладеного пошуку (`debounce`).

**Спосіб запуску:** відкрити проєкт у VS Code та запустити `index.html` через локальний HTTP-сервер **Live Server** (`http://127.0.0.1:5500/`). Відкриття через протокол `file://` не підтримується для ES Modules і `fetch()`. Для перекомпіляції стилів за потреби використовується команда `npx sass scss/main.scss:css/styles.css`.

## Структура модулів

У `index.html` підключено єдиний вхідний модуль `<script type="module" src="js/main.js"></script>`, який імпортує три незалежні модулі (циклічних залежностей немає):

- `data/items.json` — зовнішнє джерело даних (8 книг, 4 категорії, унікальні додатні `id`, локальні шляхи в `images/`).
- `js/api.js` — асинхронне завантаження `loadItems()` через `new URL("../data/items.json", import.meta.url)` і `fetch()`, перевірка `response.ok`, формату масиву, обов'язкових полів, унікальності `id`, допустимих категорій та безпечності локальних шляхів зображень.
- `js/catalog.js` — чиста функція фільтрації `filterItems(items, query, category)` і безпечний рендеринг `renderItems(items, grid, count, empty)` через `document.createElement()`, `textContent`, `DocumentFragment` і `replaceChildren()` без `innerHTML`.
- `js/utils.js` — утиліта `debounce(fn, delay = 300)` на основі замикання та функції вищого порядку.
- `js/main.js` — точка входу, керування станами завантаження/помилки у `init()` через `try/catch/finally`, одноразова реєстрація обробників подій і підтримка збережених взаємодій (блок «Показати більше» та лічильник цілі читання).
